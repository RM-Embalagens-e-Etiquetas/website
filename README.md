# RM Embalagens

Site institucional da RM Embalagens, agora em Next.js (App Router).

## Scripts

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
npm start
```

Os estilos LESS em `src/styles/less` são compilados automaticamente para `src/app/globals.css` ao rodar `dev` ou `build`.
